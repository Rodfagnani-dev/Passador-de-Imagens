# Passa Imagens

Este projeto é um carrossel simples que permite passar imagens utilizando os botões **Voltar** e **Avançar**.

O HTML e o CSS são básicos, pois o projeto foi criado principalmente para treinar a lógica de programação com JavaScript, incluindo seleção de elementos, eventos de clique, funções, condições e manipulação de classes.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar

Abra o arquivo `index.html` em um navegador e utilize os botões para navegar entre as imagens.
